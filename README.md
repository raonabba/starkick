# ✨ 별까기

> 바둑알로 즐기는 별자리 대전 보드게임

황도 12궁의 신화 이야기와 함께, 별(알)을 튕겨 상대방의 별을 모두 밀어내는 2인용 게임입니다.

## 🎮 게임 방법

1. **별자리 선택** — 플레이어 1, 2가 각각 12궁 중 하나를 선택
2. **별 발사** — 내 별을 드래그해서 당겼다 놓으면 반대 방향으로 발사
3. **승리 조건** — 상대방의 별 5개를 모두 밖으로 밀어내면 승리!
4. **특수 스킬** — 각 별자리 고유 스킬을 3턴마다 사용 가능

## ⭐ 특수 스킬 목록

| 별자리 | 스킬 | 효과 |
|---|---|---|
| 양자리 ♈ | 황금 돌진 | 2배 파워 발사 |
| 황소자리 ♉ | 철벽 방어 | 3초간 무적 쉴드 |
| 쌍둥이자리 ♊ | 쌍둥이 분신 | 상대 교란 |
| 게자리 ♋ | 집게 포착 | 상대 별 4초 동결 |
| 사자자리 ♌ | 불사의 포효 | 경계 밖 나가도 부활 |
| 처녀자리 ♍ | 풍요의 씨앗 | 죽은 별 소환 |
| 천칭자리 ♎ | 평형의 저울 | 전체 위치 초기화 |
| 전갈자리 ♏ | 독침 공격 | 다음 공격 2배 |
| 사수자리 ♐ | 황금 화살 | 직선 관통 발사 |
| 염소자리 ♑ | 변신 탈출 | 상대 별 랜덤 순간이동 |
| 물병자리 ♒ | 생명의 물 | 죽은 별 안전 소환 |
| 물고기자리 ♓ | 아프로디테의 도망 | 내 별 원하는 위치로 이동 |
