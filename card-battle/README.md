# 별까기 카드배틀 (0단계 시제품)

초등학생이 그리스·로마 신화와 별자리 이야기를 배우면서 수학을 연습하는 카드게임입니다.
`index.html` 파일 하나로 동작하고, 설치 없이 브라우저에서 바로 열립니다.

## 규칙

- 12별자리 중 하나를 영웅으로 골라 컴퓨터와 1:1로 대결합니다. 영웅 체력은 200입니다.
- 별빛(마나)은 매 턴 1씩 늘어 최대 6까지 찹니다. 손패는 최대 5장, 자리는 최대 5칸입니다.
- **하수인이 공격하거나 공격 마법을 쓸 때마다 수학 문제(보기 4개)가 나옵니다.**
  - 정답: 카드 공격력 100%로 공격
  - 오답·시간 초과: "정답이 아니에요!"와 함께 정답, 풀이 힌트를 보여주고, 공격력이 카드 공격력의 10~50% 중 무작위로 줄어듭니다 (최소 1)
- 하수인끼리 싸우면 맞은 쪽도 자기 공격력만큼 반격합니다 (반격은 문제 없음).
- 키워드 4가지: 방패(먼저 공격받아야 함), 돌진(바로 공격), 보호막(첫 공격 1번 막음), 치유(나올 때 영웅 체력 회복).
- 컴퓨터도 공격할 때 같은 문제를 풉니다. 아이가 지켜볼 수 있도록 화면에 보여주며, 난이도별 정답률은 60~80%입니다.
- 게임이 끝나면 정답률과 틀린 문제("다시 보는 문제"), 내 별자리의 신화 이야기가 나옵니다.

## 난이도 (화면에는 학년을 표시하지 않음)

| 표시 | 내부 범위 | 문제 | 제한시간 |
|---|---|---|---|
| 이지 | 1~3학년 | 받아올림·받아내림 덧셈·뺄셈, 세 자리 덧셈·뺄셈, 곱셈구구 | 15초 |
| 노멀 | 3~4학년 | (두·세 자리)×(한 자리), (두 자리)×(두 자리), 나눗셈의 몫과 나머지, 분모가 같은 분수 | 10초 |
| 하드 | 5~6학년 | 혼합 계산 순서, 최대공약수·최소공배수, 분모가 다른 분수 덧셈, 소수 곱셈·나눗셈 | 10초 |
| 슈퍼 | 1~6학년 | 위 문제가 모두 섞임 | 문제에 따라 5·7·10초 |

**세 자리 이상 수가 나오는 문제(예: 638 − 471, 183 × 5)는 제한시간이 10초 더 늘어납니다** (이지 25초, 노멀 20초, 슈퍼 15·17초). 문제 창에 "세 자리 수 +10초"로 표시됩니다.

오답 보기는 아이들이 자주 하는 실수로 만듭니다 (받아올림을 잊음, 분모끼리 더함, 계산 순서를 틀림, 소수점 위치 등).

## 테스트

```bash
node card-battle/test-engine.js
```

문제 20,000개(정답 검증, 보기 중복 없음), 오답 피해 범위, 컴퓨터끼리 500판 시뮬레이션을 검사합니다.
